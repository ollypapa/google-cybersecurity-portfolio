
# Botium Toys Security Audit

## Project Overview

This project involved conducting a security audit for Botium Toys by reviewing the company's scope, goals, and risk assessment report and completing a controls and compliance checklist.

The assessment focused on identifying which security controls and compliance best practices were currently in place and which areas needed improvement.

## Areas Assessed

- Least privilege
- Disaster recovery
- Password policies
- Separation of duties
- Firewall
- Intrusion detection system (IDS)
- Backups
- Antivirus
- Legacy system monitoring
- Encryption
- Password management
- Physical security
- CCTV surveillance
- Fire detection and prevention

## Compliance Areas

- Payment Card Industry Data Security Standard (PCI DSS)
- General Data Protection Regulation (GDPR)
- System and Organizations Controls (SOC)

## Key Findings

The risk assessment identified several security gaps, including:

- Employees had access to internally stored data and may have been able to access customer PII/SPII and cardholder data.
- Encryption was not being used to protect locally stored credit card information.
- Least privilege and separation of duties had not been implemented.
- There was no intrusion detection system.
- There were no disaster recovery plans or backups of critical data.
- The existing password policy did not meet current complexity requirements.
- There was no centralized password management system.
- Asset identification and classification needed improvement.
